# Changelog

All notable changes to Huntly are documented in this file.

## [1.0.0] - Initial Release

- Added the Huntly Windows installer, bundled Python runtime, and desktop window.
- Kept the local browser dashboard and added a guided business, AI, and mailbox setup.
- Added credentials directly to Discover and four accent colours in Settings → Appearance.
- Updated Huntly's branding and published a demo and screenshots using sample data.
- Preserved Sellbird's upstream history and copyright notices.
